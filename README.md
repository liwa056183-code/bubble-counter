# Floating Bubble Counter Android APK Project
تطبيق الدائرة العائمة الصفراء فوق جميع التطبيقات مع عداد نقرات والتحكم بالحجم.

## طريقة بناء ملف الـ APK:
1. فك ضغط هذا المجلد.
2. افتح مجلد المشروع في برنامج Android Studio عبر "Open".
3. انتظر ثوانٍ لاكتمال مزامنة Gradle Sync.
4. اضغط من القائمة العلوية على: Build -> Build Bundle(s) / APK(s) -> Build APK(s).
5. سيتم استخراج ملف الـ APK وتثبيته مباشرة على هاتفك!
